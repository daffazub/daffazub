## 🧑‍💻 Tentang Saya

Halo! Saya **Daffa Zubair Rabbani**, seorang **Web & IoT Developer** yang berdedikasi di bidang teknologi informasi. Saat ini saya adalah mahasiswa aktif **Teknik Informatika Politeknik Negeri Jember** dan lulusan **Teknik Komputer dan Jaringan SMK Yadika 13**.

Saya memiliki ketertarikan mendalam pada pengembangan **perangkat lunak multi-platform** (Web & Mobile) serta **integrasi perangkat keras berbasis Internet of Things (IoT)**. Berpengalaman membangun aplikasi web, sistem mobile berbasis **Flutter**, integrasi backend (**Laravel, Firebase, Supabase**), hingga sistem berbasis **Computer Vision** — seperti deteksi gestur tubuh dan deteksi pose keselamatan kerja via **Raspberry Pi & YOLOv8**.

Selama **Praktik Kerja Lapangan 5 bulan** di **BKPSDM Kota Bekasi**, saya mengasah kemampuan **kolaborasi tim**, **ketelitian pengelolaan data digital**, dan **komunikasi publik** yang responsif. Sebagai pribadi **pembelajar cepat** dan **gigih menyelesaikan masalah**, saya selalu termotivasi menciptakan solusi teknologi yang **aplikatif** dan **berdampak nyata**.
